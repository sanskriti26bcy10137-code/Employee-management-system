# Employee Management System

## Problem Statement

Keeping employee information on paper or in separate places can make it difficult to find and update records. This project provides a simple program for keeping basic employee details in one place.

The program manages employee records along with salary, department and attendance information.

## Objectives

- To store employee details.
- To make employee information easy to search.
- To manage salary information.
- To keep department information.
- To record attendance.
- To generate simple reports.

## Scope

This project is a basic console application. It is intended for small-scale use and for demonstrating Python programming concepts.

## Target Users

The system can be used by a small office or by someone learning the basics of programming.

## Main Modules

1. Employee Records
2. Salary
3. Department
4. Attendance
5. Reports

## Concepts Used

- Variables and expressions
- Input and output
- Conditional statements
- for and while loops
- Functions
- Lists
- Dictionaries
