# Employee Management System

## Introduction

This is a small Python project for managing employee information. I made it as a console application so that the main programming concepts from the CSE1021 subject can be used directly.

The program keeps employee details such as ID, name, age, department, salary and attendance.

## What the program can do

- Add, search, update and delete employees
- Display employee records
- Add and view salary
- Calculate yearly salary
- Display departments
- Find employees department-wise
- Record attendance
- Calculate attendance percentage
- Show simple reports

## Concepts used

The project uses input/output, if-else, loops, functions, lists, dictionaries, sets and simple calculations.

## How to run

Install Python 3 and open this folder in Command Prompt or PowerShell.

Run:

python main.py

## Files

employee.py - employee related functions
